# 具有真實導入潛力的空間情報國家韌性決策原型
### 坡地韌性哨兵——地景複發熱點觀測站｜OSSInt 2026 跨國空間情報於國家韌性應用學生競賽

這不是「AI 自動判定災害」的黑箱系統，而是一套**候選排序＋證據鏈**的決策輔助原型：從水保署
97,500+ 張災害通報影像中，依「不同年份出現次數」（而非照片總數）篩出全台**100 個長期複發的
地質不穩定熱點**，再用十年以上的衛星歷史影像逐一比對變遷，並用透明的**巡查優先級 A–D 規則**
（複發性／近期變遷證據／地形起伏／資料信心）把一個籠統的自動分數轉成「下一步該做什麼」，
供有限的巡查人力排序——每一個排序背後都附上可回溯、可驗證的證據鏈，而不是一個要人盲目
相信的分數。

**這不是純技術 demo，是一個誠實的資料治理系統**：11 個熱點做過完整人工目視覆核，其中
只有 1 個同時「對位成功」且「訊號乾淨」，其餘要嘛是已知的系統性陷阱（對位失敗偽陽性、
雲影誤判、跨世代影像色調差異灌水），要嘛雖有真實訊號但被雜訊墊高分數——這些「自動化
比對會在哪裡騙人」的案例，全部誠實記錄在「深度驗證台帳」分頁，首頁並直接展示其中最具
代表性的兩個真實命中與一個真實誤報。

## 資料範圍（公開展示版）

- **全部 100 個熱點**：清單、地圖、巡查優先級 A–D 完整可用（僅需中繼資料，不需影像）。
- **11 個已深度驗證的熱點**：額外含完整的多期歷史影像比對面板（四聯圖／拖曳捲簾比對／
  SSIM 熱區／通報座標標記）。其餘 89 個熱點點開後會誠實顯示「尚無擷取資料」，而不是
  假裝有資料。
- 完整 100 個熱點的原始擷取影像（~30GB）與研究用原始碼在另一份私有研究倉庫維護；
  這份公開版本只帶可公開展示、可重現的部分。

## 技術架構

Flask 後端 + Leaflet 前端單頁應用；比對引擎為 SSIM 像素級變遷偵測
（`scripts/ge_change_detect.py`）；地形起伏取自 Cesium World Terrain（`CESIUM_ION_TOKEN`
為選配 Space secret，未設定時等高線疊圖開關自動隱藏，不影響其餘功能）。系統架構、API
一覽與資料治理原則見 [ARCHITECTURE.md](ARCHITECTURE.md)；完整開發過程與除錯記錄維護在
私有研究倉庫，這份公開版本為精簡發布版。

## 治理原則

所有自動化分數（含巡查優先級）皆為**排序候選建議**，不代表災害已確定發生或其嚴重程度；
人工覆核結論永遠優先於自動分數（見台帳 `warn`/`bad` 案例在巡查優先級中如何被正確降級）。

## 現場展示可靠性

- **`/api/health`**：即時回報核心資料檔案、離線可播放熱點數、線上擷取/Playwright 可用性、
  Cesium 地形 token 設定狀態，供展示前自我檢查——不是行銷宣稱，每一項都是可驗證的具體事實。
  頁面右上角「系統狀態」徽章即時顯示。
- **`DEMO_MODE=1`**（選配 Space variable）：現場展示時可主動開啟，停用依賴外部服務
  （Google Earth Web 即時擷取）的功能，只保留完全由本機快取資料驅動的核心內容（100 熱點
  清單/地圖/優先級、11 個已驗證熱點的完整比對面板、深度驗證台帳），避免展示現場受外部
  網站當下狀況影響。開啟時首頁與頁首會顯示明顯的離線展示模式提示。
