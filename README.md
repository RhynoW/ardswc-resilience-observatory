# 具有真實導入潛力的空間情報國家韌性決策原型
### 坡地韌性哨兵——地景複發熱點觀測站｜開源空間資訊於國家韌性應用黑客松競賽：OSSInt 2026

這不是「AI 自動判定災害」的黑箱系統，而是一套**候選排序＋證據鏈**的決策輔助原型：從水保署
歷史影像平台（2026-09-22 即時查詢共 105,131 筆）中只取真正的災害紀錄（災害事件＋媒體報導災情地點），
把同一災害的後續追蹤與重複拍攝合併成**獨立災害事件**，以 250 m 網格篩出全台**100 個長期複發的
地質不穩定熱點**，再用 Sentinel-2 年度衛星影像（2017 起每年一期）逐一比對變遷，並用透明的**巡查優先級 A–D 規則**
（複發性／近期變遷證據／地形起伏／資料信心）把一個籠統的自動分數轉成「下一步該做什麼」，
供有限的巡查人力排序——每一個排序背後都附上可回溯、可驗證的證據鏈，而不是一個要人盲目
相信的分數。

**這不是純技術 demo，是一個誠實的資料治理系統**：熱點與影像證據已於 2026-09-22 依平台即時資料
全面重建（可重現的腳本見 [ARCHITECTURE.md](ARCHITECTURE.md) §7.3）。舊版 11 筆人工目視覆核屬於舊熱點
位置，已全部清空——舊版覆核中沒有一個能在影像上明確指認為乾淨命中，累積下來的系統性陷阱清單
（對位失敗偽陽性、雲影誤判、季節／色調差異灌水）保留在「巡查清單與證據」分頁，作為覆核新熱點的
檢查表。新的 100 個熱點目前皆尚未人工覆核，A 級代表「優先確認候選」，不是災害已確認。

**主要使用者**：水保署、各分署及地方政府的巡查與判讀人員——定位為「巡查候選排序與證據鏈工具」，
不作為民眾安全判斷工具。**已知限制**：歷史通報有密度偏差（道路可達處、特定年度或單位較常拍攝），
紀錄多不必然代表災害多，高排名熱點須經人工查證。

## 資料範圍（公開展示版）

- **全部 100 個熱點**：清單、地圖、巡查優先級 A–D、Sentinel-2 年度比對面板（前後期／SSIM 熱區／
  拖曳捲簾比對）全部可用；巡查清單與單點摘要可匯出。
- 原始衛星影格（PNG）與四聯合成圖不隨公開版發布，只帶比對 JSON、世界檔與網頁用的小尺寸面板。

## 技術架構

Flask 後端 + Leaflet 前端單頁應用；比對引擎為 SSIM 像素級變遷偵測
（`scripts/ge_change_detect.py`）；地形起伏取自內政部地政司全臺灣 20 m DTM
（`scripts/prepare_dtm20.py` 下載整備；沒有時退回 Cesium World Terrain，需選配 `CESIUM_ION_TOKEN`；
兩者皆無時等高線疊圖開關自動隱藏，不影響其餘功能）；100 熱點的影像證據為
Sentinel-2（Sentinel Hub WMTS 512 圖磚、10 m、每年一期，`scripts/s2_verify_hotspots.py`；線上補充時間軸需選配
`SENTINEL_INSTANCE_ID` secret），只適用面積級變化；Esri Wayback 歷史影像用於任意座標的線上分析。系統架構、API
一覽與資料治理原則見 [ARCHITECTURE.md](ARCHITECTURE.md)；完整開發過程與除錯記錄維護在
私有研究倉庫，這份公開版本為精簡發布版。

## 治理原則

所有自動化分數（含巡查優先級）皆為**排序候選建議**，不代表災害已確定發生或其嚴重程度；
人工覆核結論永遠優先於自動分數（台帳標記 `warn`/`bad` 的熱點會依規則自動降級，不進 A 級）。

## 現場展示可靠性

- **`/api/health`**：即時回報核心資料檔案、離線可播放熱點數、線上擷取可用性、
  地形來源（20 m DTM／Cesium token）狀態，供展示前自我檢查——不是行銷宣稱，每一項都是可驗證的具體事實。
  頁面右上角「系統狀態」徽章即時顯示。
- **`DEMO_MODE=1`**（選配 Space variable）：現場展示時可主動開啟，停用依賴外部服務
  （Esri Wayback 即時擷取）的功能，只保留完全由本機快取資料驅動的核心內容（100 熱點
  清單/地圖/優先級、Sentinel-2 年度比對面板、量化驗證與人工覆核台帳、巡查清單匯出），避免展示現場受外部
  網站當下狀況影響。開啟時首頁與頁首會顯示明顯的離線展示模式提示。
